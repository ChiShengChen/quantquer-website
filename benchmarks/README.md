# Quantquer public benchmark evidence

Visit [the benchmark catalog](/labs/benchmarks/) for readable tables in Traditional Chinese or [in English](/en/labs/benchmarks/). The [result index](results/index.json) follows the [result schema](schemas/result.schema.json). Each result identifies the public artifact, data scope, environment, command and known limits.

| Evidence type | Definition |
| --- | --- |
| Measured | Values captured directly during the described execution of a benchmark. |
| Replayed | Public review or re-execution of a recorded trace or pinned fixtures. |
| Simulated | Values computed from a numerical or illustrative model and its stated inputs. |

## Reproduction

- **Target NPU capture.** Run `node benchmarks/scripts/vision-npu.mjs --help` for hardware-specific capture requirements and review output. The validator checks a locally obtained capture, its model hashes and provider placement before reporting metrics for review.
- **Synthetic scheduling policies.** The [five-policy comparison](/labs/evidence/gpu/#policy-simulation) runs a fixed workload independently of the hardware trace. Run `node --test scripts/test-vnext-gpu-policy.mjs` to check policy-specific timing and resource limits.

- **Vision CPU baseline.** See [runtime requirements and methodology](reports/vision-cpu.md), [raw samples](/assets/evidence/vision/benchmark.json) and the [runner](/scripts/reproduce-vision.py). A new run produces timing specific to the machine. The public result captures the original desktop CPU run.
- **GPU admission and memory.** Review the [public event and sample trace](/assets/evidence/gpu/trace.json) and [replay](/labs/evidence/gpu/). Run `node --test scripts/test-vnext-labs.mjs` to reproduce the trace checks. The private scheduler and per-process instrumentation that generated the trace are outside the public reproduction package.
- **Photonic mesh.** Run `node --test scripts/test-photonic-mesh.mjs` for the complex-amplitude solver and its reference test cases. The [fixed simulated fixture](results/photonic-fixture.json) is regenerated by `node scripts/build-vnext-labs.mjs`.
- **Paper Evidence.** Check out [the pinned public source](https://github.com/ChiShengChen/paper-evidence/tree/ac6e83c63252049bbccbf19bbf7f3dbc334ac0b7). Run `python scripts/reproduce-research-evidence.py /path/to/paper-evidence --check` in the website checkout to compare the output against the [four recorded synthetic fixtures](/assets/evidence/research/quote-gate.json).

The `timestampMeaning` property identifies a captured run date or the date assigned to a fixed fixture report. Missing measurements are listed on the catalog and have no numeric placeholders in the result index.
