# 待站主確認

| 事項 | 目前狀態 |
| --- | --- |
| 正式發布 | 本機候選與回歸可預覽。確認後依 GitHub Pages 流程合併並驗證正式站。 |
| 網頁直接詢價 | 已有可測的同源 adapter 和速率限制。需核准部署環境、收件傳輸、資料保留與實際收件。靜態版本使用既有信箱。 |

| 具名客戶與未公開資料 | 現有內容仍有公開權限需由站主週期審核；新增內容維持匿名、合成或已有來源。 |
| NPU、GPU 叢集與硬體試驗 | 提供目標硬體、規格與可披露輸入，才能發布新量測。 |
| 手術、農場影像與更多研究 | 具體場域效能、資料和未公開研究的補充須取得相應權限及原始證據。 |
