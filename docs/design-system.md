# Quantquer 設計系統

Scientific Instrument 介面用波形、頻率格線、座標式區隔與標註呈現工程資訊。品牌標語維持 **Quantify to Conquer.**，技術敘事沿用 **From Silicon to Intelligence.**

## 色彩、字體與排版

| Token | 亮色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#F6F8FB` | `#070A11` | 頁面與 Hero 底色 |
| `--bg-2` | `#FFFFFF` | `#0A0F18` | 導覽、互動區與表單 |
| `--panel` | `#FFFFFF` | `#0C121C` | 方案、案例與資料卡 |
| `--fg` | `#101A24` | `#EAEEF2` | 標題與主要文字 |
| `--fg-dim` | `#4B5765` | `#9AA6B4` | 說明與次要文字 |
| `--fg-faint` | `#5F6B79` | `#7A8796` | 圖說、次級標註 |
| `--accent` | `#004EA1` | `#2DD4BF` | 行動按鈕、連結、焦點與訊號 |
| `--line`、`--line-soft` | 深色透明邊線 | 白色透明邊線 | 卡框、編目線與表格隔線 |
| `--canvas-grid`、`--canvas-axis` | 深色透明線 | 白色透明線 | 頻率格線與基準軸 |

- 使用 Noto Serif TC 顯示標題、Noto Sans TC 顯示正文、IBM Plex Mono 顯示數值、圖註與介面短標籤。正文行高沿用 1.7。英文與繁中共用字體與層級，Hero 依字長獨立控制換行。
- 主容器 `--maxw` 為 1180 px，水平留白使用 `--pad: clamp(20px, 5vw, 64px)`。首頁區段垂直留白 24–54 px，卡片內距約 12–24 px，案例欄距 12 px。
- 導覽、按鈕沿用 2 px 圓角，表單輸入採 4 px 圓角。表面層次用底色和邊線，展開式選單使用現有陰影。焦點以主色 2 px 外框標示。聯絡欄位錯誤有文字和 `aria-invalid`。
- 圖表以現有各 Demo 色彩及狀態文字呈現。比較圖與表格應提供圖說、欄名、單位及原始資料入口。實測、模擬與專案成熟度直接用文字呈現。

## 元件

| 元件 | 結構及行為 |
| --- | --- |
| 方案卡 | 使用情境、工程能力、交付物、方案頁與對應證據兩個入口 |
| 工程案例卡 | 代表圖、來源、工程成果與可追溯證據。連結圖可開啟較大版本 |
| 技術詳頁 | 問題、限制、架構圖、實作、成果、驗證、公開範圍和相關方案。首屏三列顯示歸屬、成熟度、公開證據 |
| 證據模組 | 以資料呈現方式、條件、侷限和出處組織。Benchmark 保留本地可橫捲的表格區塊 |
| 出版物與合作方案 | 以清單與分隔線呈現發表資訊、交付物及書面確認入口 |
| 夥伴與影片 | 沿用原有圖像和來源。影片使用 poster、按下後載入的原生播放器與雙語字幕 |
| 短詢價與 RFP | 原生輸入、欄位描述、就地錯誤與即時訊息。短詢價採三個必填欄位 |

## 原有波形

- 全幅 Canvas 保留網格、PSD 包絡、主要訊號、第二諧波、視差及儀器風格圖說。兩種語系共用 `assets/studio-waveform.mjs`，公式與取樣間隔沿用原版。
- Canvas DPR 上限為 2。固定空間包絡與漸層在尺寸或主題改變時重算，動畫離開可視範圍或頁籤隱藏時暫停。減少動態偏好使用時間 0 的同一套繪圖。Canvas 設為 `aria-hidden`。
- 視覺測試固定同一視窗、主題和時間，再比對 Canvas 像素。把實案量測圖放在案例與證據頁。 [受保護元件](PROTECTED_DESIGN_COMPONENTS.md)

## 響應規則

- 桌機顯示四欄解決方案、三欄代表案例。760 px 以下採兩欄方案、一欄案例與合作區。
- 首頁 940 px 以下改用選單。共用內頁殼在 1000 px 以下改用原生展開選單。520 px 以下語言、主題、選單採緊湊標籤及最小 44 px 操作區。
- 420 px 以下縮短 Hero 垂直間距，主要及次要行動可依內容寬度換行。正文、輸入及圖解在 320 px 一樣可操作。聯絡表單在 520 px 以下改為單欄。
- 動畫與小型過渡沿用原主題與 `prefers-reduced-motion`。頁面開啟時只載入該路線使用的腳本，圖片保留尺寸與原有響應式資源。 [驗收紀錄](website-validation.md)
