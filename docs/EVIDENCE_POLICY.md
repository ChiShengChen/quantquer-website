# 工程證據發布規則

| 分類 | 公開依據 |
| --- | --- |
| 已交付工程 | 可核對範圍或已發表的匿名交付紀錄，保留可披露的限制 |
| 實測基準 | 附方法、硬體、條件及可披露的測試結果 |
| 可重現實驗 | 固定資料、版本、程式與方法，可比對輸出 |
| 公開研究 | 已發表論文或公開研究紀錄，歸屬到作者或研究合作 |
| 互動原型 | 可操作介面，標示輸入、測試條件及限制 |
| 示意展示 | 合成案例、數學模型或參考架構 |
| 研發中 | 公開現況、驗證條件及尚待資料 |

每個案例分開呈現證據、專案歸屬、開發階段與可公開範圍。「實測」只用於原始紀錄足以支撐的硬體、資料與測試條件。圖解如引用相關論文，連結說明圖與研究的關係。所有合成示例提示資料來源和模型假設。

手術中體內紗布與豬隻追蹤展示維持匿名及方法說明。臨床效能、動物場域條件、具名客戶、私有訓練資料、硬體成效和商業關係需有可核對的原始資料及公開權限。
