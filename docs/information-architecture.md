# Quantquer 資訊架構

繁中首頁 `/` 和英文首頁 `/en/` 使用同一套「首頁摘要 → 工程證據 → 詢價」結構。98 個既有索引路徑沿用，配對頁以 `/en/` 對應。原證據和展示頁保留 `?lang=en`、`#english` 等相容入口。 [站點地圖](../sitemap.xml)

| 導覽 | 目的地 | 下一層 |
| --- | --- | --- |
| 首頁 | `/` | 原版波形、品牌與實績連結、四個方案、三個預設案例、三個可展開案例、證據與 Labs、四種合作、公司夥伴、詢價 |
| 解決方案 | `/solutions/` | `semiconductor-edge-ai`、`ai-reliability`、`gpu-infrastructure`、`scientific-ai` 四個首頁入口，其餘既有方案從索引瀏覽 |
| 工程案例 | `/work/` | 16 個案例、AND 條件搜尋與分享連結、案例詳情、圖解及對應證據 |
| Labs | `/labs/` | `projects/` 搜尋與成熟度、`demos/` 互動、`benchmarks/` 結果、`evidence/` 證據，並連到研究與工程筆記 |
| 公司 | `/company/` | 公司與創辦人、能力簡介、夥伴、合作與交付條件 |
| 聯絡 | `/contact/` | 三欄短表單、直接 Email、完整 RFP、Project Planner、可選會議連結 |

服務與合作模式、研究發表及能力簡介由首頁、相關頁面和頁尾進入。主導覽在行動版以語言、主題及選單保留入口。標題、CTA、卡片順序、證據分類與導覽由兩種語系共用生成器，兩者可切到對應路徑。

## 使用路徑

- 工程主管從方案卡核對交付物，跟進案例與公開證據後，透過短詢價提供問題。
- 研發或採購人員從案例、Benchmark、能力 PDF 與合作條件比對驗收範圍，再用完整 RFP 提供裝置、時程及技術需求。
- 研究人員從 Labs 進入互動模型、原始 JSON、重跑說明、程式庫或論文。案例頁可反向連到適用方案與其證據。
- 現有訪客可用原先主題頁、案例錨點及互動網址。首頁的舊錨點會展開索引與對應內容。無 JavaScript 時原生展開區與公開連結可直接使用。
