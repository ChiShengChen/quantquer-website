重現方法

Python 腳本停用模糊比對，重跑四組範例並核對引文前後各 200 字元內的數字。段落與數字均為合成資料。這組測試只驗證引文位置與數字上下文，未呼叫 LLM 語意判斷，也未量測問答品質。

git clone https://github.com/ChiShengChen/paper-evidence.git
git -C paper-evidence checkout ac6e83c63252049bbccbf19bbf7f3dbc334ac0b7
python scripts/reproduce-research-evidence.py paper-evidence --check
